Studie D · Lage und Karte statt Menü

Schwerpunkt: Dashboard und Sternenkarte statt Menü (Idee des Owners, 2026-11-23, [E]). Der Einstieg ist ein Dashboard, das zeigt, was die anderen tun. Die Sternenkarte ersetzt das Menü: hineinzoomen in eine eigene Welt heißt bauen, von Welt zu Ziel ziehen heißt fliegen. Nur ein kleines Menü bleibt (Lexikon, Soziales, Optionen + Admin). Nachrichten sind ein Chat unten rechts, ein Tracker unten zeigt die neuesten Ereignisse; groß stehen sie im Dashboard. Nichts bleibt vom alten Aufbau.
  • [E] Dashboard als Einstieg · Karte statt Menü · kleines Menü · Chat unten rechts · Tracker unten.
  • [V] Bauen auf der Oberfläche der Welt (#158), kompakt [E] daneben.
  • [V] Flotte durch Ziehen, Auftrag im Ring, Vorlage füllt die Schiffe.
  • [V] Berichte gibt es nicht als Seite: Tracker → Dashboard groß; Teilen in den Chat.

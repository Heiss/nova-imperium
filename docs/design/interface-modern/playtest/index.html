Nova Imperium · Playtest

Wir gehen den Spielablauf Schritt für Schritt durch, immer nur eine Situation auf einmal. Du siehst drei Varianten ohne Etikett. Wähle die, die dir besser gefällt, schreib dazu, was dir daran gefällt, und geh mit „Weiter“ zur nächsten. Erst nach deiner Wahl steht da, welcher Schwerpunkt dahintersteckt. Ein Klick auf ein Bild vergrößert es.

Alles wird gespeichert, sobald du wählst oder schreibst; Claude liest es und passt die nächsten Situationen daran an. Neue Situationen erscheinen von selbst, ohne dass die Seite neu lädt. Situationen kommen ruhig mehrmals, damit wir sicher sind.

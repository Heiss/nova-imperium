Nach der Anmeldung mit Passwort erscheint das Feld für den Code aus der E-Mail sofort; die E-Mail enthält jetzt auch einen Link, der die Anmeldung in diesem Browser abschließt. Nach 30 Sekunden kannst du einen neuen Code anfordern. Unter „Optionen“ kannst du eine Authenticator-App einrichten; dann kommt der Code aus der App statt per E-Mail.

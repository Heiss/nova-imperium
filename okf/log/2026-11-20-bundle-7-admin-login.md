#118, bundle 7 (Admin, login and the install state; the owner put it into the update of 2026-11-22 on 2026-11-19, package 8 follows after it) [V]: „Admin“ is a Svelte component. `Admin.svelte` renders `adminPage()` of the new `logic/admin.ts` (tabs, universe settings with the live round settings, invitation, Endzeit, „Rundenberichte“, „Neue Runde“, „Servernachricht“); the dialogs „Neue Runde“ and „Endzeit einläuten“ are components (`RoundDialog.svelte`, `EndzeitDialog.svelte`) shown by `modal()`; the round archive is one component (`RoundArchive.svelte`, `archivePage()` of `logic/round-archive.ts`) that „Optionen“ and the admin share, so `{@html}` is gone from `Options.svelte`. The draft of the settings of the admin (`logic/settings-draft.ts`) works as before. The install state was already moved to `features/install.ts`.

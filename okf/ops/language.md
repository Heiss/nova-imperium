# Decisions

* **[E]** Development is in English as in muffelblog: code, comments, test
  names, commit messages, pull requests, README, docs and this bundle (round 1,
  confirmed against the hand-over note in round 4).
* **[E]** The game interface stays German: texts in the browser, messages of
  the server to players, the invitation mail. There is no language switch.
* **[V]** Log messages of the server and the operator command are English
  (for the operator, not for players).
